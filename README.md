# 공기저항 실험실

Python 표준 라이브러리로 만든 2차원 공기저항 시뮬레이션입니다. **다운로드한 뒤 인터넷 없이 실행**할 수 있습니다. 외부 패키지, 서버, API 키가 필요하지 않습니다.

## 로컬 실행

1. Python 3.10 이상을 설치합니다. Windows/macOS는 python.org 배포판의 Tcl/Tk 포함 설치를 권장합니다.
2. 이 저장소를 ZIP으로 다운로드하고 압축을 풉니다.
3. 해당 폴더에서 실행합니다.

```sh
python main.py
```

macOS/Linux에서는 `python3 main.py`를 사용할 수 있습니다. Linux에서 tkinter가 없다면 배포판 패키지(예: Ubuntu의 `sudo apt install python3-tk`)를 먼저 설치하세요. 최초 Python/Tk 설치 이후에는 네트워크가 필요 없습니다. 그래픽 데스크톱이 필요하며, `no display name` 오류는 화면 없는 서버에서 실행했다는 뜻입니다.

## 사용 방법

- 형상: 구, 정육면체, 유선형체
- 입력: 초기 속력(m/s), 질량(kg), 크기(m), 발사각(수평 기준 °), 발사 높이(m)
- 크기: 구는 **반지름**, 정육면체는 **한 변**, 유선형체는 **장축 전체 길이**입니다.
- 실행하면 공기저항이 있는 궤적과 없는 궤적, 비행시간·사거리·최고 높이를 비교합니다.
- 재생 버튼이나 시간 슬라이더로 운동에너지·위치에너지·공기저항으로 잃은 에너지를 확인합니다. 기본 화면은 착지 순간입니다.
- CSV 저장은 조건과 모든 계산 시점의 위치·속도·에너지를 내보냅니다. 입력을 바꾼 뒤 다시 실행하기 전까지 결과는 직전 실험을 나타냅니다.

## 물리 모델

298 K, 1 atm의 건조 공기: 밀도 `101325/(287.05×298) ≈ 1.1845 kg/m³`, 점성계수 `1.837×10⁻⁵ Pa·s`. 중력가속도 `9.80665 m/s²`.

`m dv/dt = (0, -mg) - ½ρ A Cd |v| v`, `Re = ρ|v|L/μ`를 RK4로 적분합니다. 지면 도달 시각을 이분 탐색으로 구합니다. 항력이 큰 경우 시간 간격을 줄입니다.

| 형상 | 투영 면적 A | 특성 길이 L | 항력계수 Cd |
|---|---|---|---|
| 구 (반지름 r) | πr² | 2r | Re<1000: 24/Re × (1+0.15Re^0.687), 그 외 0.44 |
| 정육면체 (변 a) | a² | a | 24/Re + 1.05 |
| 유선형체 (장축 ℓ) | π(ℓ/8)² | ℓ/4 | 24/Re + 0.10 |

구의 저속 항력은 Schiller–Naumann 상관식입니다. 정육면체·유선형체는 대표적인 관성 항력계수에 저속 점성항을 더한 **교육용 근사**이며 정밀한 실험 예측 모델이 아닙니다. 유선형체는 장축:단축=4:1로 고정합니다. 정육면체는 면이 유동을 향하고 유선형체는 장축이 속도 방향을 유지한다고 가정합니다. 속력이 0일 때는 발산하는 Cd를 직접 계산하지 않고 유한한 항력 표현을 사용합니다.

바람·회전·양력·부력·대기 변화·항력 위기는 제외합니다. 축별 축척은 다를 수 있습니다. 위치에너지 기준은 지면이며, 에너지 손실은 `초기 역학적 에너지 - 현재 역학적 에너지`입니다. 착지 직전까지 계산하므로 지면 충돌 손실은 제외합니다. 지면에서 아래 방향 또는 정지 상태로 시작하면 즉시 종료합니다.

극단적 조합은 계산 한도(30만 단계)에 도달할 수 있으며 오류로 안내합니다. 허용 입력 범위는 화면의 ‘모델과 가정 보기’에 명시되어 있습니다.
